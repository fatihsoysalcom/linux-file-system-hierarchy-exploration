# Linux File System Hierarchy Exploration

This Python script demonstrates the hierarchical structure of the Linux file system. It starts from the root directory '/' and recursively lists subdirectories and files up to a specified depth, illustrating the organization of system components.

## Language

`python`

## How to Run

Run the script using: python explore_fs.py
This will print a tree-like structure of the Linux file system starting from the root.
